# 🌤 Peek-a-Sky

Peek-a-Sky is a React-based weather application built using Vite and WeatherAPI.

## Features

- Search weather by city
- Get current weather information
- View a 5-day weather forecast
- Use current location to fetch weather
- Display temperature, humidity, pressure, wind speed, UV index, visibility, sunrise, and sunset
- Error handling for invalid cities
- Loading indicator while fetching data
- Responsive user interface

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- WeatherAPI

## How to Run

1. Install dependencies

```
npm install
```

2. Start the development server

```
npm run dev
```

3. Open

```
http://localhost:5173
```
