# Reflection

## What was hardest?

The most challenging part was integrating an AI model into the application while ensuring it provided meaningful recommendations instead of acting as a simple chatbot. Managing asynchronous API calls and handling possible failures without affecting the weather functionality also required careful implementation.

## What would you do differently next time?

I would organize the project architecture earlier, write tests alongside feature development, and improve SEO further. I would also plan UI components before implementation to reduce later refactoring.

## One thing I learned

This project showed me that production-ready software is much more than writing code. Accessibility, testing, deployment, documentation, and error handling are just as important as implementing the main features.
